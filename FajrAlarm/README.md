# منبّه الفجر

المصدر من الملف المرسل. المنبّهان يعملان بالنسبة لفجر كفر الشيخ ويمكن اختيار نغمة مستقلة لكل منهما؛ الإعدادات الصوتية مشتركة. سجّل الباركود بالكاميرا قبل تفعيل أي منبّه. ارفع صوت المنبّه من إعدادات الجهاز بنفسك وجرّب مستوى الصوت بعيداً عن الأذن؛ التضخيم المرتفع قد يضر السمع والسماعة ولا يضمن تجاوز الحد المادي للجهاز.

تحتاج السماح بالكاميرا والإشعارات والمنبّهات الدقيقة والعرض فوق شاشة القفل بحسب النظام. على هواتف شاومي راجع التشغيل التلقائي والبطارية بدون قيود. توجد وسيلة إيقاف احتياطية إذا تعذّر فتح الكاميرا أو لم يُسجّل مفتاح، ويتوقف الرنين تلقائياً بعد 15 دقيقة؛ لا تعتمد عليه دون اختبار فعلي للجهاز وإعداداته.

GitHub Actions يبني `assembleDebug` وينشر APK تجريبياً موقّعاً بمفتاح debug، وليس إصداراً إنتاجياً موقّعاً بمفتاح إصدار. يلزم تجربة الرنين والشاشة مقفلة والباركود الصحيح والخاطئ وإعادة التشغيل قبل الاعتماد عليه.
