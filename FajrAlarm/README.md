# منبّه الصلاة — نسخة تجريبية

- ٥ منبهات للصلوات، لكل منها تشغيل مستقل ونغمة. التطبيق يجلب صف «كفر الشيخ» الرسمي اليومي من موقع الهيئة المصرية العامة للمساحة عبر HTTPS ويحفظه للجهاز؛ موقع الهيئة يذكر المدينة ولا يوفر صفاً منفصلاً لقسم أول. عند تعذر مزامنة يوم ما يستخدم التطبيق حساباً فلكياً تقريبيًا يظهر بهذه الصفة؛ قد يختلف عن الهيئة، ولا يجوز الادعاء أنه مطابق لها تمامًا.
- المنبّه السادس بوقت يدوي ولمرة أو يوميًا؛ والمنبّه السريع مؤقت مستقل لمرة واحدة. يمكن تحديد الإيقاف بكود أو بدونه لكل منهما. منبّهات الصلوات تتطلب كوداً محفوظاً. يمكن حفظ أكثر من كود، وأي كود محفوظ مقبول.
- في الماسح إطار إرشادي متوسط وزر فلاش عند دعم الجهاز. الكاميرا قد تقرأ كوداً خارج الإطار؛ الإطار إرشادي فقط.
- توجد وسيلة إيقاف احتياطية إذا لم تعمل الكاميرا أو لم توجد أكواد، ويتوقف كل رنين بعد 15 دقيقة. اضبط صوت المنبّه في الجهاز واحذر التضخيم العالي. قد لا يدعم جهازك المضخّم أو العرض فوق شاشة القفل.
- يحتاج السماح بالإشعارات والمنبّهات الدقيقة والكاميرا، وعلى Xiaomi يحتاج مراجعة التشغيل التلقائي والبطارية وشاشة القفل. أندرويد قد يلغي الجدولة عند فرض إيقاف التطبيق، والعمل في الخلفية غير مضمون على كل الأجهزة.
- البناء على GitHub Actions موقّع بمفتاح debug مؤقت وهو للتجربة لا إصدار إنتاجي. توقيع كل بناء جديد قد يختلف، وقد يتطلب إزالة النسخة السابقة قبل تثبيت الجديدة مما يمسح بياناتها. لا تعتمد عليه قبل اختبار فعلي لمواقيت الهيئة والباركود والفلاش والمنبهات والجهاز مقفلًا وبعد إعادة التشغيل.
